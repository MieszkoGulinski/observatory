# Scheduler web GUI

## Page sections:

- Schedule display
- Create observation(s)
- Edit/delete observation(s)
- Display last system status
- System load graphs

## Quick start

To run the GUI locally:

```bash
npm run dev
```

To build and serve the GUI for production:

```bash
npm run build
npm run start
```
