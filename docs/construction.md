# Construction notes

The following parts are used:

- **Canon EOS 50D** DSLR camera
- **200 mm M42 mount lens**
- **Raspberry Pi** (I have version 1B, but any version with an Ethernet port will work)
- Clone of **Arduino Nano**, 3.3V version
- 2x **stepper motor** (recycled from an old floppy disk drive)
- 2x **magnetic encoder module** (AS5600) for angle sensing
- **I2C multiplexer** (TCA9548A / PCA9548A) for connecting multiple devices
- **Temperature and humidity sensor** (AHT20)
- 2x **temperature sensor** (DS18B20) for camera and rain sensor
- **Rain sensor**
- **Infrared thermometer** (MLX90614) for measuring sky temperature to detect clouds
- **Ethernet cable** - to connect the Pi to the PC to control the observatory and to download the acquired data.
